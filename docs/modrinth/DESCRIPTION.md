# DrakesNanotech

An ultra-endgame **Slimefun expansion** about programmable matter, ARC engineering, gamma science,
advanced suits and safely contained cosmic artifacts.

Build infrastructure—not instant god items. Sixty launch entries form seven connected research
branches, from salvaged servos and palladium coils to nanoforges, gamma chambers, six dangerous
artifacts and two gauntlet platforms.

### Highlights

- 48 materials, tools, suit components and cosmic artifacts
- 12 textured-head machines with complete in-game specifications
- visible particle-first Repulsor combat that cannot target players
- escalating bare-artifact exposure with clear warnings
- Mark I, III, V, XLII, L, Hulkbuster and Rescue foundations
- zero block explosions and bounded visual effects
- English-only items, lore, menus and documentation

**Server-side:** clients need no mod. Requires Java 21, Paper 1.21.11 and the Drakes Slimefun Core.

This is an original unofficial science-fantasy project. It contains no official logos, character
likenesses or copied franchise assets.
